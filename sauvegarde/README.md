# Dossier de sauvegarde

Placez ici le fichier `veille-sports-partage.json` téléchargé via le bouton **« Enregistrer les données »** de l'application (en écrasant l'ancien).

Au début d'une session, cliquez sur **« Charger les données »** et sélectionnez ce même fichier pour repartir des dernières décisions de l'équipe.

Si ce dossier se trouve sur un espace réseau partagé (comme le reste du dossier de l'application), tous les agents de l'équipe travaillent alors sur le même fichier — voir le README principal, section « Décisions par structure, et liste partagée entre agents ».
